# 🎓 AI-Based Student Performance Analytics System

An intelligent web-based platform that helps educational institutions manage, analyze, and predict student academic performance using data analytics and Machine Learning.

---

## 📖 Overview

The **AI-Based Student Performance Analytics System** is designed to assist administrators and faculty members in monitoring student progress through attendance records, assessment scores, examination results, and performance analytics.

The system utilizes **Machine Learning** to predict student performance and identify academically at-risk students. It also provides interactive dashboards, visual analytics, and AI-assisted insights to support data-driven decision-making.

## 🤖 Machine Learning Module

The analytics service is implemented as an independent Flask API.

### API Responsibilities

- Predict Student Performance
- Student Analytics
- Risk Classification
- Performance Insights
- Recommendation Generation

Communication between the ASP.NET application and the Flask API is performed through REST APIs using JSON.
